# The-Tech-Academy-Basic-C-Sharp-Projects
Will contain basic C# .NET framework Projects

PROJECTS:

Abstract Classes Assignment:
Implemented an inheritance hierarchy using abstract classes to demonstrate shared behavior, required method overrides, and polymorphic design.

Calling Method Assignment:
Created methods that perform operations and return results, then invoked them from the main program to reinforce method calling and parameter passing.

Calling Methods Assignment / Calling Methods Assignment:
Built a class with multiple methods performing mathematical operations, showcasing method overloading and structured program flow.

Car Insurance Assignment:
Developed a console application that evaluates user input (age, DUI history, speeding tickets) to determine insurance eligibility using conditional logic.

Console App Array:
Worked with arrays to store, access, and manipulate collections of data, including iteration and index-based operations.

Console App Assignment Parts 1–6 / Console App Assignment:
Constructed a multi‑part console application demonstrating loops, conditionals, lists, exception handling, and user interaction across several incremental tasks.

Console App Strings and Integers:
Handled user input, converted strings to integers, and performed arithmetic operations while managing potential conversion errors.

Constructor Assignment / ConstructorAssignment:
Created classes with overloaded constructors to initialize objects in different ways, reinforcing object‑oriented design principles.

DateTime Assignment / DateTimeAssignment:
Used the DateTime class to display the current time, perform date arithmetic, and output future or past dates based on user input.

Input Assignment / InputAssignment:
Built a simple console program that collects user input, processes it, and outputs results, focusing on data validation and interaction.

Lambda Expression / LambdaExpression:
Used lambda expressions with LINQ to filter, sort, and query collections, demonstrating functional-style programming in C#.

Main Method Assignment / Main Method Assignment:
Explored the structure of the Main() method, including parameters, return types, and program entry behavior.

Methods and Objects Assignment:
Created classes with properties and methods, instantiated objects, and demonstrated how methods operate on object state.

My Math Assessment:
Developed a math‑focused class with custom methods performing calculations, showcasing method creation, return values, and encapsulation.

Operator Assignment:
Overloaded operators (such as == and !=) to compare custom objects, reinforcing how operator behavior can be customized.

Parameters Assignment:
Created methods with optional, named, and default parameters to demonstrate flexible method invocation patterns.

Parsing Enum Assignment:
Defined enums and parsed string input into enum values, demonstrating type safety and structured categorical data.

Polymorphism:
Implemented polymorphic behavior using interfaces or base classes, allowing different object types to be treated uniformly.

Struct Assignment:
Created and used struct types to represent lightweight value‑type objects, comparing them to classes.

Student Report:
Built a program that collects student information, stores it in objects or lists, and outputs a formatted report.

TryCatch Assignment / TryCatchAssignment:
Implemented exception handling using try, catch, and finally blocks to manage runtime errors gracefully.

TwentyOne / TwentyOne:
Developed a simplified Blackjack (21) game using classes, loops, and game logic to simulate card dealing and scoring.

WebApplication / Views / Home:
Created an ASP.NET MVC or Razor Pages web application with a Home view, demonstrating routing, controllers, and dynamic page rendering.
